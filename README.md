
# Starter Kit

Welcome to the Cedar & Code Starter Kit!
Thank you for downloading this free resource. This kit is designed to help you stop procrastinating and start building.

What's Inside This Zip:

1. index.html: Your barebones responsive layout.
2. Launch_Checklist.pdf: The 10-point checklist for a pro launch.
3. Resources.txt: A list of my favorite free design tools.

How to Use the Template:

- Open index.html in your browser to see the current layout.
- Edit the text and colors inside the style tags to match your vibe.
- Drag and drop this folder into Netlify to go live in seconds.
